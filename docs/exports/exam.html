ข้อคำตอบแนวคิด
1Aแยกตัวประกอบเป็น (x − 2)(x − 3) = 0 จึงได้ x = 2 หรือ x = 3
2Aแยกตัวประกอบเป็น (x + 2)(x − 3) = 0 จึงได้ x = −2 หรือ x = 3
3Aแจกแจงได้ x² + x − 12 = 0 และแยกเป็น (x + 4)(x − 3) = 0
4Ax² − 9 = (x − 3)(x + 3) จึงได้ x = −3 หรือ x = 3
5Aหา 3 และ 4 ซึ่งคูณกันได้ 12 และบวกกันได้ 7 แล้วใช้สมบัติผลคูณเป็นศูนย์
6Aแยกเป็น (x + 3)(x + 2) = 0 จึงได้ x = −3 หรือ x = −2
7Aจากสมบัติผลคูณเป็นศูนย์ ได้ x + 2 = 0 หรือ x − 6 = 0
8Aแยกเป็น (x + 3)(x − 5) = 0 แล้วใช้สมบัติผลคูณเป็นศูนย์
9Aใช้ผลต่างกำลังสองแล้วตั้ง x − 4 = 0 หรือ x + 4 = 0
10Aแยกเป็น (x + 4)(x − 2) = 0 จึงได้ x = −4 หรือ x = 2
11Aเขียนเป็น (x − 5)² = 0 จึงมีรากซ้ำ x = 5
12Aดึงตัวร่วมเป็น 2x(x − 4) = 0 จึงได้ x = 0 หรือ x = 4
